## Metric interpretation

Earlier experiments use eight-person LOSO and session-mean or person-mean
aggregation. Later experiments pool held-out predictions for all ten public
people and score participant/session/context cells. Do not compare these
percentages as one continuous benchmark.

On the common all-ten-person OOF cell metric: Lag4 57.44%; Lag4+balance
58.53%; Lag4+CNN+balance 60.23%; SWAD CNN fusion 60.61%; conservative Lag4
transduction over SWAD fusion 62.72%. These are exploratory public-CV results,
not independently confirmed sealed scores.

Historical RUN_STATUS files describe the moment they were written. Prefer
final results reports when both exist. The transduction Kaggle run has ERROR
status due to an intermediate reporting race, but all 11 folds completed;
the complete report was recovered locally from saved outputs.

## Data and generated artifacts

Public PROTEUS: https://doi.org/10.82901/nemar.nm000290 (CC-BY-4.0).
Preparation commands and environment setup are in
[reproduction/README.md](reproduction/README.md) and the experiment READMEs.
Caches are regenerated by the corresponding preparation scripts.

Saved model weights, reference forecasts, logits and archives are intentionally
absent. Some analysis/build scripts therefore require the original local or
Kaggle outputs before execution. This is a code/report archive, not a fully
self-contained data bundle.

Generated notebooks have execution outputs cleared. Embedded base64 input
bundles were removed and replaced with a local-file reference. Use the
corresponding `build_notebook.py` / `build_notebooks.py` with local inputs to
recreate executable Kaggle notebooks. The experiment source scripts remain
unchanged; notebook sanitization is recorded in the snapshot manifest.
