## 1. Первый диагностический тест: масштабирование касательных признаков

part3.tex:315–353 доказывает согласованное ортогональное преобразование
касательных координат при общем невырожденном смешивании каналов и статическом
аффинно-инвариантном римановом среднем. L2-логрег сохраняет предсказания после
соответствующего переобучения. В замечании явно исключена покоординатная
стандартизация. Наш bci/riemann.py:81–82 применяет StandardScaler.

Предлагаемый эксперимент: исходный логрег, текущие признаки со StandardScaler
против центрирования и одного скалярного масштаба для всего вектора. Общий
масштаб можно вычислить как квадратный корень из средней дисперсии координат
на train, чтобы приблизительно согласовать общую величину признаков и C.
Это наша адаптация, а не эксперимент автора диссертации.

Условия теоремы не выполнены целиком: у нас OAS, log-Euclidean prior и онлайн
обновление опоры. Удаление StandardScaler не восстанавливает автоматически
полную аффинную инвариантность. Общее A для всей выборки также не моделирует
произвольные разные A_s для разных людей. Отдельный последующий тест:
статическая AIRM-опора против log-Euclidean при согласованном сравнении.

## 2. Число электродов и шум ковариации

part3.tex:461–526: при независимых гауссовских отсчетах верхняя оценка ошибки
ковариации в геодезической метрике имеет порядок h/sqrt(T). Это достаточная
оценка при ее условиях, а не универсальный оптимум h. EEG-проверка:814–823
обсуждает зависимость отсчетов и меньшее эффективное количество наблюдений.

В нашем Lag4 20 физических электродов становятся40 координатами ковариации,
а касательный вектор имеет820 координат. На окно приходится476 выровненных
временных отсчетов. T здесь не число размеченных окон. Зависимость и фильтрация
не позволяют буквально применять iid-границу к EEG или к OAS-оценке.

Предлагаемая небольшая сетка физического числа каналов:8/12/16/20. С Lag4 это
ковариации16/24/32/40 и136/300/528/820 касательных признаков соответственно.
Выбор и настройка только по обучающим людям во вложенной групповой валидации.

## 3. Классовые маски: главное архитектурное заимствование

part3.tex:26–128: для каждого класса обучается собственная маска каналов;
ковариации этих подмножеств получают отдельные опорные точки и касательные
описания, затем описания всех классов конкатенируются перед классификатором.
Опора каждого поднабора усредняет все train-объекты в этом поднаборе,
а не только объекты соответствующего класса. На inference все маски применяются
к любому окну; знать его метку не требуется.

Для нашего трехклассового EEG предлагаемая адаптация — обучать три устойчивые
маски по дискриминативности логмощностей в полосах, агрегированной по людям.
Оригинальный отбор корреляцией сырого fMRI с временным индикатором стимула
не переносится буквально: в осциллирующем EEG различие мощности не требует
различия среднего, а в готовом размеченном окне индикатор класса может быть
константой. Маски строить только на outer train; подбор h — внутри train по
людям. Сохранять разнообразие ансамбля, например часть случайных подмножеств.

Размерность классовых ветвей суммируется: при8 физических каналах в каждой
из3 Lag4-ветвей получится3*136=408 признаков; при10 —3*210=630. Нельзя считать,
что любое уменьшение размера одной маски уменьшает общую размерность.

## Условно полезно и ограничения переноса

part4.tex:56–130 и227–228: интерполяция недостающих каналов по координатам
сенсоров и masked flow matching. Использовать только при выявленных пропусках
или плохих каналах; сначала простой метод, оцененный по downstream BA, а не
только reconstruction RMSE. Не считать эту часть доказательством выигрыша
на классификации motor imagery.

part2.tex: лаг — задержка отклика на стимул, в основном гемодинамическая для
fMRI. Наш Lag4 — внутреннее временное вложение EEG на33.3мс. Это разные лаги;
пятисекундный сдвиг из мультимодальной главы не является настройкой для EEG.

Главные classification-результаты part3.tex:532–770 относятся к индивидуальным
моделям fMRI,8 классам и96 объектам/человека. EEG-эксперимент814–823 также
использует валидацию внутри каждого человека. Доказательств улучшения LOSO
PROTEUS в репозитории нет. Лес тоже не является предметом этого исследования.
В опубликованном models.py:376–396 есть Covariances -> Shrinkage(1e-3) ->
TangentSpace; идеализированная теорема не равна готовому коду без оговорок.

Последовательность предложенных абляций: scaling -> channel count ->
class-specific selection -> reference geometry. Основной протокол — прежний
LOSO по людям; поздняя сессия отдельно. Публичный test не использовать для
подбора этих вариантов. Предыдущие70 прогонов меняли только классификатор;
новые гипотезы изменяют представление и должны оцениваться отдельным протоколом.
