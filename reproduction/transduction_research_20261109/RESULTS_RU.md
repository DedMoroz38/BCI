# Результаты: причинная трансдукция

Version 1 рассчитала все 11 фолдов и 2706 оценок: 123 настройки на каждую из
двух исходных моделей. Kaggle завершился со статусом ERROR из-за гонки при
сборке промежуточного отчёта. Все прогнозы и метрики фолдов сохранены;
итоговый отчёт собран локально. Перезапуска вычислений не было.
Локально исправлена причина: сборщик теперь учитывает только фолды с готовым
JSON-отчётом, который записывается после прогнозов и расчёта метрик.

## Основное сравнение

Проценты balanced accuracy. OOF — среднее по ячейкам человек × сессия ×
интерфейс после объединения всех 10 LOSO-фолдов; поздние сессии — отдельный
протокол later_last. Эти числа нельзя смешивать со средним по людям.

| Метод | OOF cell BA | Поздние сессии |
|---|---:|---:|
| Исходный Lag4 без balance | 57,44% | 64,64% |
| Lag4 + balance1 | 58,53% | 65,36% |
| Прежний лучший Lag4 + SWAD + balance1 | 60,61% | 67,76% |
| Авторская трансдукция с обычными ковариациями поверх смеси | 61,36% | 68,29% |
| Lag4-трансдукция с жёстким балансом поверх смеси | 62,12% | 68,25% |
| Общие log-cov координаты + плавное включение поверх смеси | 62,46% | 70,05% |
| Согласование двух представлений, JS/.05, поверх смеси | 62,41% | 71,92% |
| **Мягкая Lag4-трансдукция, 50% силы, поверх смеси** | **62,72%** | **71,11%** |

Победитель: lag_running__soft50_half / lag4_swad.
Прирост к прежней лучшей смеси: +2,1095 п.п. OOF, +3,3541 п.п. later_last.
NLL .965741 → .862356; Brier .577222 → .508482.
Среднее BA по людям .626480 → .649228, но это другая агрегация, не headline OOF.

## Что именно выиграло

Исходный прогноз: .7 Lag4 + .3 среднее softmax(logits/4) двух SWAD CNN.
По текущему и прошлым окнам сессии строятся Lag4 OAS ковариации в пяти полосах
4–8, 8–13, 13–20, 20–30, 4–40 Гц. Опорная точка — текущее лог-евклидово
среднее с весом исходного обучающего среднего 5. Касательные признаки каждого
окна сохраняются в координатах его тогдашней опорной точки.

После 20 окон: Gram-PCA с k=min(20,n//3), пять итераций soft-LDA, shrinkage=.5,
beta=1; масштабирование масс классов с tau=.5. Финальный прогноз — среднее
50/50 этой трансдукции и прежнего balance1-прогноза. В первые 19 окон — только
прежний прогноз. Состояние сбрасывается на каждой сессии. Целевые метки
используются только после получения прогнозов, для подсчёта метрик.

## Выводы по направлениям

- Перенос авторской трансдукции полезен даже без новых признаков: 60,61 → 61,36%.
- Лаговые признаки дают более сильный результат: с теми же жёсткими
  настройками 61,36 → 62,12%.
- Ослабление коррекции особенно полезно. Мягкий баланс сам по себе не
  гарантирует выигрыш: lag_running soft50 = 61,91%, hard = 62,12%; soft50
  с 50% примесью исходного прогноза = 62,72%.
- Общая log-cov система координат конкурентоспособна: 62,46%. Фиксированная
  обучающая опора и объединение Gram двух представлений лидера не обошли.
- Классово-сбалансированная опорная точка по псевдометкам: лучший вариант
  смеси 62,40%; более сложная опора не превзошла победившую простую схему.
- Снижение адаптации при несогласии двух представлений даёт 62,41% и
  71,92% later_last. Это сильный второй кандидат для следующего сравнения.
- Без CNN лучший вариант Lag4 (sharpened pseudo reference, beta=.5):
  61,51% OOF и 69,29% later_last против 58,53% и 65,36% без трансдукции.

## По людям у победителя

Улучшение у 8/10 людей. Изменения в п.п.:
P01 +8,90; P02 +1,89; P03 −2,20; P04 +3,23; P05 −3,58;
P06 +0,38; P07 +3,29; P08 +0,66; P09 +10,00; P10 +0,16.
Прирост неравномерный: особенно помогло P01 и P09, ухудшило P03 и P05.

Это выбор из 246 вариантов на многократно использованной публичной CV,
поэтому величина выигрыша может быть оптимистичной. Новый скрытый тест не
проверялся. Нейросети не переобучались: результат показывает пользу адаптации
прогнозов, а не устранение переобучения их обучения.
