# Опорные матрицы: контролируемое сравнение

Запускается из `/Users/den1shh/Documents/diploma` в уже созданном `reproduction/.venv`.
Использует прежние данные и неизменённые исходные репозитории.

## Варианты

- Контроль: накопительное лог-евклидово обновление, прежние 29 проверенных результатов.
- `euclid_cumulative`: накопительное арифметическое среднее ковариаций.
- `riemann_recursive`: рекурсивная аффинно-инвариантная геодезическая, шаг 1/(5+t).
- `logeuclid_ema`: нормированные экспоненциальные веса, decay=0.95.

Начальная матрица из обучения и её вес 5 одинаковы для всех. Меняется сессионное
обновление и соответствующие обучающие признаки; scaler и классификаторы
переобучаются с исходными настройками. Риманов вариант — индуктивная оценка,
а не точное среднее Фреше всей истории. Для EMA шаг стремится к 0.05 после разогрева.

Это повтор **потокового EEG-эксперимента таблицы 2**. У синтетических экспериментов
статьи фиксирована единичная опорная точка и нет сессионного обновления; они здесь
не меняются.

## Запуск

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
export MPLCONFIGDIR="$PWD/reproduction/.cache/matplotlib"

# Проверки формул, причинности и контрольного адаптера + прежние проверки.
reproduction/.venv/bin/python -m pytest -q reproduction/reference_ablation/test_references.py reproduction/scripts

# Проверка неизменности данных/окружения и фиксация конфигурации до вычислений.
reproduction/.venv/bin/python -u reproduction/reference_ablation/run.py --initialize

# 87 новых оценок, до четырёх независимых локальных процессов.
# Завершённые задачи пропускаются при повторном запуске.
reproduction/.venv/bin/python -u reproduction/reference_ablation/launch.py --workers 4

# Проверка всех 116 файлов предсказаний официальными метриками, таблицы и отчёт.
reproduction/.venv/bin/python reproduction/reference_ablation/analyze.py
```

Отдельная группа, например:

```bash
reproduction/.venv/bin/python -u reproduction/reference_ablation/run.py \
  --variant logeuclid_ema --model forest20
```

Есть `--protocol cv` и `--protocol test`. Как в исходном эксперименте,
для forest12 тестовая часть не добавляется. Для test обучение только на train,
без добавления val. По тестовым результатам параметры не подбираются.

## Файлы

- `experiment.json`: формулы, параметры, версии и хеши до начала эксперимента.
- `references.py`: единственная замена сессионного обновления; исходные модели не переписаны.
- `run.py`: тот же протокол, сохранение каждого предсказания и проверка случайных деревьев.
- `results/<variant>/`: 29 JSON и 29 NPZ на вариант.
- `logs/`: журналы групп.
- `comparison.csv`: 12 строк (4 опорные матрицы × 3 классификатора).
- `paired_loso.csv`: парные разницы по восьми людям (72 строки).
- `fold_scores.csv`: 116 оценок (87 новых + 29 контрольных).
- `verification.json`, `verified_jobs.json`: независимая проверка официальными метриками.
- `REPORT.md`, `comparison.png`: отчёт и график.

Не запускайте две копии одной группы одновременно в одну папку. Конфигурация
защищена от случайного изменения кода, библиотек, данных и контрольных результатов
между продолжениями запуска.
